# Logo de la structure

Déposer ici le logo officiel fourni par la Cellule des Statistiques, sous le nom **`logo.png`**
(PNG, fond transparent de préférence, environ 400 px de large).

Il apparaît alors automatiquement :
- dans l'en-tête et la barre latérale de l'interface, et comme icône de l'onglet du navigateur ;
- en en-tête des documents Word (commentaires, notes d'analyse, notes stratégiques).

Sans ce fichier, le prototype affiche le nom seul : aucun logo n'est inventé ni téléchargé.
Nom, sous-titre et couleurs se règlent dans `config.yaml`, section `interface`.
